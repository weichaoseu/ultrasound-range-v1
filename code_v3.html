使用方法：
1. 两部手机都立起来正对，扬声器和麦克风朝向对方，避免平放桌面（平放时直达信号弱、反射强）。
2. A 机点“发射端”，B 机点“接收端”，两边频率/时长/周期保持一致。
3. B 机放在已知距离，等“累积距离变化”稳定后点“记录校准点”。
4. 缓慢移动 B，观察累积值是否连续变化。靠近为负，远离为正。
5. 到达待测位置后点“测量距离”。
提示：如果累积值仍然不动，说明直达信号太弱、跟踪到了反射峰。拉近两部手机（10–20 cm），调高发射音量，确认 SNR 稳定在 3 以上再试。
