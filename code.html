使用方法：

2. B 放在已知距离（如 30 cm），等峰值稳定后点“记录校准点”。

宽带优势：扫频 1–20 kHz 的理论距离分辨率约 0.9 cm（受硬件频响影响，实际可能 2–5 cm）。
注意：手机扬声器在 1 kHz 以下和 16 kHz 以上衰减很大，若信号弱可把起始/终止频率改为 2000–16000 再试。保持 B 持续录音不要停，先近后远缓慢移动。
