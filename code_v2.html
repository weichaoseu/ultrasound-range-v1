使用方法：
1. A 机点“发射端”，B 机点“接收端”，两边频率/时长/周期保持一致。
2. 先近距离（10–30 cm）确认 B 机显示“已锁定信号”，SNR 稳定在 3 以上。
3. B 放在已知距离，等数值稳定后点“记录校准点”。
4. 缓慢移动 B（<10 cm/s），观察“累积距离变化”是否随移动连续变化。
5. 到达待测位置后点“测量距离”。
提示：18 kHz 以上手机扬声器衰减很大，先用 2000–8000 Hz 验证链路，再逐步加宽频带。信号丢失后累积会中断，建议重新校准。
